# Hrudhi performance and identity correction

Tracking: [issue #13](https://github.com/ArohaRetreat/natura/issues/13). The 0.5.2 website is not a finished uniform character-performance kit. The original illustrated face is authoritative. Technical SVG anatomy is a different drawing and cannot satisfy that identity requirement. A still character surrounded by motion cannot satisfy a character action.

## Verified audit

The 30 original PNG/WebP masters match the immutable original lock. Fifteen original chapter/season references are retained. Five chapter cards display static images. The 120 action files animate the simplified SVG character, as do the 15 rigs and 130 view/expression/mouth studies. Five latest films preserve the original illustration but animate scenery only. File counts, hashes and an animation timer do not establish likeness or correct performance. The local audit is `release/hrudhi-uniformity-audit.json`; it is not a family approval record.

## Required model continuity

Use the original reference for each chapter and season. No new family-photo-derived face. Keep the warm brown complexion, eye shape/spacing, nose, smile, hairline, leaf clip, clothing texture and satchel recognisable. Age changes follow the five approved-scope bands; seasonal clothing must not accidentally change face or age. Front/profile/back/expression assets must be modelled from that same identity, not the prior simplified rig. A new candidate pose sheet is a draft until inspected against the original; it does not supersede the masters or constitute a layered animation rig.

## Action acceptance

| Action | Character movement required | Does not count |
| --- | --- | --- |
| Resting | Restrained chest breathing and a plausible blink/head response | Moving scenery |
| Walking | Opposite arms and legs, knee flexion, foot lift/plant, weight transfer; feet do not slide | Translating the whole standing image |
| Talking | Visible controlled mouth articulation and conversational gesture; silent unless licensed audio is supplied | Subtitles alone or head bobbing |
| Sitting | Believable seated anatomy, hips/knees supported, relaxed hands and listening response | Squashing a standing image |
| Storytelling | Seated/open-book pose, a page or describing gesture and mouth articulation | A book beside a still character |
| Welcoming | Shoulder/elbow raise and independent hand/wrist wave, controlled return | Rotating the whole character |
| Guiding | Directional shoulder/elbow/hand gesture and natural head attention | A pulsing arrow |
| Gardening | Weight shift/bend, hand grasp, can tilt, coordinated water and recovery | Rain falling around a standing figure |

A clip must meet both likeness and its action test. Not every original flattened reference is production-ready for articulation; hidden joints, occluded clothing, seated folds and facial mouth shapes need authored layers/key poses. Do not use unreviewed cut-and-rotate pieces that expose holes, duplicate limbs or distort the original face.

## Website acceptance

Every role card must select its chapter and offer an explicit performance preview. Every action must be separately selectable with a visible description, Play, Pause, Replay and scrub controls. The displayed chapter, wardrobe, face and downloadable action must match. Use one shared identity/asset manifest for cards, workbench, gallery and films. Do not silently switch to a substitute SVG when a matching clip is unavailable. Indicate missing/review-pending assets honestly. Keep the rest of the kit accessible while repairing it; do not delete working collections to hide gaps.

Test all five chapters × three seasons × eight actions (120 combinations), not a single hero clip. Inspect beginning, key poses, transitions and finish visually; decoded-frame differences must prove character movement rather than scenery motion. Likeness remains an art review and cannot be certified by file hashes. Verify mobile controls, native playback, reduced-motion stills, captions/equivalent action descriptions, no concurrent playback, and pause/disposal on route/tab exit. Milestone selection must pin a reviewed chapter for the session; it must not drive unreviewed art live.

## Delivery state

No replacement kit is approved or published by this document. Original masters and the current release are preserved. The initial correction candidate is one Little Explorer warm-season action key-pose sheet, reviewed before expanding to every chapter/season. It is static preproduction artwork, not eight completed animations. Runway currently returns `UNAUTHORIZED` / requires reauthentication; generated performance films cannot be produced through that connector until reconnection. No paid video generation or automatic acceptance is implied.

The first walking sprite candidate was rejected on visual gait review: multiple frames repeat the same leading-leg phase instead of an alternating contact/passing cycle. It is retained only in the local review folder as a rejected candidate, with manual frame inspection. No completed walking animation or new MP4 is claimed. The eight-action key-pose candidate is static and still needs likeness review.
