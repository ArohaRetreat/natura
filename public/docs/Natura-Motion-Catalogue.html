Include additional-scenes.js beside nature-scenes.js. SVG files are static compositions; the JavaScript controller supplies the independently controlled parts and timeline. Reuse the controller instead of applying a generic whole-icon entrance.

Motion boundaries

These are occasional explanatory studies, not continuous decoration. Nothing autoplays or loops. The player supports a single active scene in the library, keyboard playback, timeline scrubbing, half-speed inspection and a static final composition for reduced motion. Cancel on hidden tabs and dispose on route exit. Do not reuse long study timing for controls; native component feedback stays at 120-220 ms.

Path drawing is confined to small explanatory SVGs. Transform and opacity carry most other movement. Text, form inputs, prices, availability and navigation stay spatially stable. No storm flashing or mandatory visitor geolocation. Weather previews remain synthetic.

Component anatomy

Experience selection uses a native checkbox, a persistent selected treatment and a small leaf articulation. Primary actions use a short press response and a directional arrow. FAQ disclosures keep native keyboard behaviour and a reversible 180 ms plus turn. Email fields use a quiet focus frame and actual native email validity. Hover motion is gated to fine pointers; reduced motion keeps state information without spatial feedback.

For keyboard focus, component feedback is immediate. Long nature studies remain explicitly playable by keyboard. Copy HTML together with the site CSS; no animation library or inline event handler is required for these native patterns.
